# ⚔️ 역사 서바이버 (History Survivor)

**초등 5학년 2학기 사회(2022 개정 교육과정) 한국사 단원**에 맞춘 역사 퀴즈 서바이벌 웹 게임입니다.
몰려오는 적을 버티다가 레벨이 오를 때마다 교과서 내용 퀴즈를 풀고, 맞히면 더 좋은 강화를 고를 수 있습니다.
빌드 도구 없이 HTML/CSS/JS만으로 동작합니다.

## 실행

**바로 하기: <https://kingseoho.github.io/historygamee/>** (GitHub Pages)

배운 단원에 맞춰 시작하려면 `play.html?unit=1&lv=1`처럼 주소를 붙여 나눠 주세요. 예) <https://kingseoho.github.io/historygamee/play.html?unit=1&lv=1>

직접 띄우려면 `play.html`을 브라우저로 열거나, 정적 서버로 띄우면 됩니다.

```bash
python3 -m http.server 8000
```

그다음 <http://localhost:8000/play.html?g=history-survivor&m=solo&grade=5&unit=3&lv=1> 로 접속합니다. (`index.html`은 이 주소로 바로 이동합니다.)

| 파라미터 | 설명 |
| --- | --- |
| `unit=1` | 1단원까지 배웠을 때: 선사·고조선 → 삼국·가야 → 통일 신라·발해 → 고려 |
| `unit=2` | 2단원까지: + 조선 → 조선 후기·개항기 |
| `unit=3` | 3단원까지: + 일제 강점기·광복(6·25 포함) |
| `lv=1` | 기본: 교과서 핵심 문제 |
| `lv=2` | 도전: 더 깊은 문제까지, 문제마다 15초 제한 |

처음 화면의 ‘수업 설정’에서 고른 값은 주소에도 반영되므로, 주소를 복사해 학생들에게 나눠 주면 같은 설정으로 시작합니다. 배운 단원 범위 밖의 시대는 시대 따라가기에서 잠기고, 6분 도전에서는 범위 안의 시대들이 6분을 나눠 가집니다.

## 교육과정 연계

| 단원 | 성취기준 | 게임 속 시대 |
| --- | --- | --- |
| 1. 유적과 유물로 살펴본 옛 사람들의 생활 | [6사04-01] 선사 시대와 고조선 | 선사·고조선 |
| | [6사04-02] 고대 사람들의 생각과 생활 | 삼국·가야, 통일 신라·발해 |
| | [6사04-03] 고려 시대 사회 모습과 생활 | 고려 |
| 2. 달라지는 시대, 변화하는 생활 모습 | [6사05-01] 조선의 유교 문화 | 조선 |
| | [6사05-02] 조선 후기 변화와 개항기 근대 문물 | 조선 후기·개항기 |
| 3. 식민 통치와 저항, 전쟁이 바꾼 사회와 생활 | [6사06-01] 식민 통치와 저항 · [6사06-02] 광복과 6·25 전쟁 | 일제 강점기·광복 |

- 문제는 유적·유물과 사람들의 생활 모습 위주로, 5학년 눈높이의 낱말로 썼습니다. 4지선다와 ○× 문제가 섞여 나옵니다.
- 지금 시대와 이미 지나온 시대의 문제만 나오므로, 게임 진행이 교과서 순서를 따라갑니다.
- 게임이 끝나면 **성취기준별 정답 수**와 **오답 노트**(정답·해설 포함)를 보여 줘 복습에 쓸 수 있습니다.
- 단원명과 성취기준은 경기도교육청 2026학년도 교육과정 자료를 기준으로 했습니다. 학교에서 쓰는 교과서에 따라 단원 이름이 조금 다를 수 있습니다.

## 게임 방법

처음 화면(진영)에서 세 가지를 할 수 있습니다.

| 메뉴 | 내용 |
| --- | --- |
| 🚩 **시대 따라가기** | 7개 시대를 교과서 순서대로 하나씩 깹니다. 한 시대는 **1막 → 2막 → 3막 → 적장**으로 이루어지고, 막마다 교과서 핵심 내용 카드를 먼저 읽습니다. 적장을 물리치면 다음 시대가 열립니다. 퀴즈는 그 시대 문제 위주로 나옵니다. |
| ⚒️ **대장간** | 게임에서 모은 엽전으로 힘·체력·빠르기·줍기·지혜·회복·막기·간격을 영구히 올립니다. |
| ⏱️ **6분 도전** | 배운 단원의 모든 시대를 6분 동안 버팁니다(자유 모드). |

- **별**: ★ 적장 물리치기 / ★★ 퀴즈 80% 이상 / ★★★ 틀린 답 1번 이하
- **출정 준비**: 출발 전에 영웅과 **시작 무기**를 고릅니다. 시대를 깨면 그 다음 시대의 영웅과 무기가 열립니다.
- **엽전**: 처치한 적 수, 깬 시대와 별 수만큼 받습니다.
- **진행 저장**: 별·엽전·강화는 학생이 쓰는 기기의 브라우저에 저장됩니다(서버 없음, 개인정보 없음). 1인 1기기라면 같은 브라우저로 링크를 열 때마다 이어집니다. 시크릿 창·게스트 모드·인터넷 기록 삭제·기기 초기화 때는 사라지므로, 처음 화면의 **💾 기록 백업 · 불러오기**에서 기록 코드(`HS1-…`)를 복사해 두었다가 새 기기에서 붙여 넣으면 되살릴 수 있습니다.
- **선생님 시연**: 주소에 `open=all`을 붙이면 모든 시대·영웅·무기가 열립니다.
- **조작**: WASD / 방향키(모바일은 화면 드래그), 공격은 자동, 퀴즈는 숫자키 1~4, Enter로 진행, Esc / P로 일시정지
- **레벨 업**: 곡옥(경험치)을 모아 레벨이 오르면 역사 퀴즈가 나옵니다. 정답이면 체력 +20과 강화 3개 중 1개, 오답이면 정답·해설을 보고 강화 1개만 받습니다.

### 영웅과 무기가 열리는 때

| 깬 시대 | 새로 열리는 영웅 | 새로 열리는 무기 |
| --- | --- | --- |
| 처음부터 | 돌이, 단군왕검 | 주먹도끼, 비파형 동검 |

| 고려 | 세종대왕, 이순신 | 신기전, 승자총통 |

| 조선 후기·개항기 | 유관순, 안중근 | 만세 함성, 의병 소총 |

## 캐릭터

캐릭터·적·아이템·장식은 모두 픽셀 아트로 그립니다. 벡터로 그린 그림을 4배로 슈퍼샘플링해 화소 격자에 맞춘 뒤 색을 묶고 1화소 외곽선을 둘러, 화면에서는 2배로 또렷하게 키웁니다. 이미지 파일 없이 `js/sprites.js` 안의 코드로 모두 만들어집니다.

| 캐릭터 | 시작 무기 | 특성 |
| --- | --- | --- |
| 돌이 (구석기 소년) | 주먹도끼 | 이동 속도 +15% |
| 단군왕검 (고조선을 세운 임금) | 비파형 동검 | 경험치 +15% |
| 주몽 (고구려를 세운 왕) | 활 | 화살 +1 |
| 김유신 (신라의 화랑·장군) | 성덕대왕신종 | 최대 체력 +30, 받는 피해 -1 |
| 세종대왕 (조선 제4대 왕) | 신기전 | 재사용 대기시간 -10% |
| 이순신 (조선 수군의 장수) | 승자총통 | 공격력 +15% |
| 정약용 (조선 후기의 실학자) | 거중기 | 경험치 +15%, 획득 범위 +30% |
| 유관순 (3·1 운동의 독립운동가) | 만세 함성 | 최대 체력 +20, 초당 체력 1 회복 |
| 안중근 (의병장·독립운동가) | 의병 소총 | 공격력 +10%, 이동 속도 +10% |

적도 시대마다 다르게 그렸습니다. 선사·고조선(들쥐·멧돼지·늑대·한나라 병사·장수), 삼국·가야(수나라 척후병·보병, 당나라 기병·친위대장), 통일 신라·발해(해적·상어·문어·해적선), 고려(거란 기병·몽골 군마·사냥매·대장), 조선(왜군 척후병·조총병·왜선·대함대), 조선 후기·개항기(병인양요 프랑스군·신미양요 미국 해병·이양선·서양 함대), 일제 강점기(일본군 보병·헌병·기병·사령관)입니다. 경험치는 곡옥 모양이고, 바닥에는 시대에 맞는 고인돌·풀·나무·연꽃 등이 놓입니다.

## 파일 구조

```
play.html        게임 화면
index.html       play.html로 이동
css/style.css    UI 스타일
js/questions.js  한국사 문제 은행 (시대·난이도별)
js/story.js      시대 따라가기의 막별 교과서 핵심 내용 카드
js/sprites.js    캐릭터·적·아이템 스프라이트 (캔버스 벡터 그림 + 프레임 캐시)

```

### 문제 추가하기

`js/questions.js`의 `QUESTIONS` 배열에 항목을 추가합니다.

```js
{ era: 4, lv: 1, std: '6사05-01', q: '문제', c: ['보기1', '보기2', '보기3', '보기4'], a: 0, exp: '해설' }
{ era: 0, lv: 1, std: '6사04-01', q: '○× 문제', c: ['○', '×'], a: 0, exp: '해설' }
```

- `era`: 0 선사·고조선, 1 삼국·가야, 2 통일 신라·발해, 3 고려, 4 조선, 5 조선 후기·개항기, 6 일제 강점기·광복. 해당 시대에 도달해야 출제됩니다.
- `std`: 성취기준 코드. 결과 화면의 성취기준별 정답에 쓰입니다.
- `lv`: 1 기본, 2 도전
- `a`: 정답 보기의 번호(0부터). 보기 순서는 출제할 때 섞입니다.
