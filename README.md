# ⚔️ 역사 서바이버 (History Survivor)

선사 시대부터 조선까지, **한국사 퀴즈를 풀며 몰려오는 적을 버티는** 뱀파이어 서바이버류 웹 게임입니다.
빌드 도구 없이 HTML/CSS/JS만으로 동작합니다.

## 실행

`play.html`을 브라우저로 열거나, 정적 서버로 띄우면 됩니다.

```bash
python3 -m http.server 8000
```

그다음 <http://localhost:8000/play.html?g=history-survivor&m=solo&grade=1> 로 접속합니다. (`index.html`은 이 주소로 바로 이동합니다.)

| 파라미터 | 설명 |
| --- | --- |
| `grade=1` | 기본 문제만 출제 |
| `grade=2` | 기본 + 심화 문제 |
| `grade=3` | 기본 + 심화 문제, 문제당 15초 제한 |

## 게임 방법

- **이동**: WASD / 방향키 (모바일은 화면 드래그)
- **공격**: 무기가 자동으로 공격합니다.
- **레벨 업**: 경험치 구슬을 모아 레벨이 오르면 역사 퀴즈가 나옵니다.
  - 정답 → 체력 +20, 강화 3개 중 1개 선택
  - 오답 → 강화 1개만 받음 (정답과 해설 표시)
- **시대**: 1분마다 시대가 바뀝니다 (선사 → 고조선 → 삼국 → 남북국 → 고려 → 조선). 각 시대 40초에 보스가 나오고, 쓰러뜨리면 보물상자(무료 강화)를 줍니다.
- **목표**: 6분 동안 살아남기. 게임이 끝나면 **오답 노트**로 틀린 문제를 복습할 수 있습니다.
- **일시정지**: Esc / P

## 캐릭터

모든 캐릭터는 이모지 대신 캔버스에 직접 그린 벡터 스프라이트(걷기 애니메이션 6프레임, 피격 시 하얗게 번쩍임)로 표현됩니다.

| 캐릭터 | 시작 무기 | 특성 |
| --- | --- | --- |
| 돌이 (구석기 소년) | 🪓 주먹도끼 | 이동 속도 +15% |
| 주몽 (고구려를 세운 왕) | 🏹 활 | 화살 +1 |
| 김유신 (신라의 화랑·장군) | 🗡️ 비파형 동검 | 최대 체력 +30, 받는 피해 -1 |
| 세종대왕 (조선 제4대 왕) | 🔔 성덕대왕신종 | 경험치 +20% |
| 이순신 (조선 수군의 장수) | 🚀 신기전 | 공격력 +15% |

적도 시대마다 다르게 그렸습니다. 선사(들쥐·멧돼지·늑대·매머드), 고조선(독사·호랑이·한나라 병사·장수), 삼국(수나라 척후병·보병, 당나라 기병·친위대장), 남북국(해적·상어·문어·해적선), 고려(거란 기병·몽골 군마·사냥매·대장), 조선(왜군 척후병·조총병·왜선·대함대)입니다.

## 파일 구조

```
play.html        게임 화면
index.html       play.html로 이동
css/style.css    UI 스타일
js/questions.js  한국사 문제 은행 (시대·난이도별)
js/sprites.js    캐릭터·적·아이템 스프라이트 (캔버스 벡터 그림 + 프레임 캐시)
js/game.js       게임 엔진 (이동, 전투, 스폰, 퀴즈, 강화)
```

### 문제 추가하기

`js/questions.js`의 `QUESTIONS` 배열에 항목을 추가합니다.

```js
{ era: 5, lv: 1, q: '문제', c: ['보기1', '보기2', '보기3', '보기4'], a: 0, exp: '해설' }
```

- `era`: 0 선사, 1 고조선, 2 삼국, 3 남북국, 4 고려, 5 조선. 해당 시대에 도달해야 출제됩니다.
- `lv`: 1 기본, 2 심화
- `a`: 정답 보기의 번호(0부터). 보기 순서는 출제할 때 섞입니다.
